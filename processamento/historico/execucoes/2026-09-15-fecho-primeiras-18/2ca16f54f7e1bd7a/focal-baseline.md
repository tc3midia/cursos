# 5.0 - Os tipos de segmentações do Meta Ads

## Contexto da aula
A aula apresenta a segmentação como a escolha dos públicos que verão as campanhas no Meta Ads.
Ela enumera os tipos de segmentação e posiciona os públicos semelhantes dentro dos públicos personalizados.
Também demonstra onde acessar a área de Públicos e onde criar um público durante a criação de uma campanha.
O detalhamento de cada tipo de público fica para as próximas aulas.

## Unidades

Segmentar campanhas é escolher os públicos para os quais o anúncio aparecerá.
Anunciar para as pessoas certas é apresentado como uma parte importante para os anúncios funcionarem.

Os tipos apresentados são públicos personalizados, localização, idade, gênero, idioma e interesses ou direcionamento detalhado, incluindo cargos.
O professor chama esse conjunto de cardápio de possibilidades de público.

tipo: conceito

Públicos personalizados têm subdivisões, entre elas os públicos semelhantes.
Para a Meta, o público semelhante é considerado um público personalizado, embora o professor veja espaço para outra categoria.

### U:2ca16f54f7e1bd7a:004 — Abrir a aba de Públicos pelas ferramentas
```yaml
tipo: procedimento
plataforma: [meta]
tema: publicos
tarefas: [montar-publicos-personalizados]
fonte: fala
faixa: "00:01:54–00:03:09"
perecivel: true
confianca: alta
versao: 1
```
Pré-condição: estar no Gerenciador de Anúncios do Meta.
1. Abra o menu de ferramentas e use o atalho de Públicos.
2. Como alternativa, abra Todas as ferramentas, entre na seção Anunciar e selecione Públicos.
3. Confirme a abertura da aba de Públicos ou Audiências; os dois caminhos levam ao mesmo local.

### U:2ca16f54f7e1bd7a:005 — Criar público durante a configuração do conjunto
```yaml
tipo: procedimento
plataforma: [meta]
tema: publicos
tarefas: [montar-publicos-personalizados, montar-publicos-semelhantes, definir-segmentacao-demografica-e-interesses]
fonte: fala
faixa: "00:03:09–00:04:20"
perecivel: true
confianca: media
versao: 1
nota: "O professor cita controles de público com o nome pronunciado como 'Adventade Plus' e deixa a explicação para outro momento."
```
Pré-condição: estar criando uma campanha e configurando o conjunto de anúncios, sem a seleção de controles de público citada pelo professor.
1. Na área de público do conjunto, use o botão de criar.
2. Selecione público personalizado ou público semelhante, ou defina localização, idade, gênero ou direcionamento detalhado.
3. Use essa área para criar o público dentro da própria campanha.

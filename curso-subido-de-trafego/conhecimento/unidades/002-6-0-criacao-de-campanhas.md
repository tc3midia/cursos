# 6.0 - Criação de campanhas

## Contexto da aula

A aula apresenta a sequência didática para aprender a criar campanhas no Meta Ads.
As próximas aulas detalham, separadamente, configurações que compõem a estrutura da campanha.
A criação prática dos tipos de campanha fica para depois do estudo dessas partes.
O professor pede que o aluno não pule as aulas de fundamentos das configurações.

## Unidades

### U:42508f24eb7b3b3b:001 — A estrutura de campanha será estudada por configurações
```yaml
tipo: conceito
plataforma: [meta]
tema: estrutura-de-campanha
tarefas: []
fonte: fala
faixa: 00:00:00–00:00:35
perecivel: false
confianca: alta
versao: 1
```
As próximas aulas abordam isoladamente elementos da estrutura, como nomenclatura, objetivo, orçamento, público, lance e programação.

### U:42508f24eb7b3b3b:002 — Entenda as partes antes de criar campanhas na prática
```yaml
tipo: decisao
plataforma: [meta]
tema: estrutura-de-campanha
tarefas: [criar-campanha]
fonte: fala
faixa: 00:00:35–00:01:46
perecivel: false
confianca: alta
versao: 1
```
Quando for aprender a criar campanhas, estude primeiro cada componente isoladamente; depois crie, em prática, os tipos de campanha.

### U:42508f24eb7b3b3b:003 — Não pule as aulas sobre cada configuração
```yaml
tipo: regra
plataforma: [meta]
tema: fundamentos-e-carreira
tarefas: [formar-se-como-gestor]
fonte: fala
faixa: 00:01:06–00:02:22
perecivel: false
confianca: alta
versao: 1
```
Não pule as aulas que explicam separadamente as configurações da campanha.

### U:42508f24eb7b3b3b:004 — Dominar componentes permite decidir suas combinações
```yaml
tipo: conceito
plataforma: [meta]
tema: fundamentos-e-carreira
tarefas: [formar-se-como-gestor]
fonte: fala
faixa: 00:01:46–00:02:22
perecivel: false
confianca: alta
versao: 1
```
Entender cada componente permite combinar a estrutura segundo o próprio critério, em vez de apenas reproduzir uma campanha demonstrada.
